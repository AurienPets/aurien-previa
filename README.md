# aurien-previa

Prévia do site institucional da **Aurien**, publicada apenas para revisão.

- **Não é o site oficial.** O domínio aurien.com.br não está configurado aqui.
- Não indexar: `robots.txt` com `Disallow: /` e `<meta name="robots" content="noindex, nofollow">` em todas as páginas.
- As políticas de privacidade do Validi e do Aurien Pets estão **em elaboração** e não valem como documento vigente.
- Validi e Aurien Pets estão **em desenvolvimento**.
- Só os arquivos estáticos da prévia. Nenhum código dos aplicativos.
