# aurien-previa

Prévia do site institucional da **Aurien**, publicada apenas para revisão.

- **Não é o site oficial.** O domínio aurien.com.br não está configurado aqui e não deve ser apontado para esta publicação.
- Pedido de não indexação: `robots.txt` com `Disallow: /` e `<meta name="robots" content="noindex, nofollow">` em todas as páginas.
- As políticas de privacidade do Validi e do Aurien Pets estão em **rascunho** e não valem como documento vigente.
- Validi e Aurien Pets estão **em desenvolvimento** e não estão disponíveis para download.
- Este repositório contém só os arquivos estáticos necessários para a prévia. Não contém código dos aplicativos.

Conteúdo gerado a partir do projeto do site; este repositório é descartável e será removido ao fim da revisão.
